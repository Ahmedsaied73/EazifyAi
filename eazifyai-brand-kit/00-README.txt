EazifyAI brand kit

01-logo: logo as SVG (vector, for web and print) and transparent PNG (for socials and platforms).
   mark-small = the simpler hand + spark version for tabs, avatars and small sizes.
02-social: og-image-1200x630.png = the picture shown when a link is shared on WhatsApp, Facebook, LinkedIn.
   avatar-800x800.png = profile picture. banner-1500x500.png = cover banner for X, LinkedIn, Facebook pages.
   banner-source.html = editable source of the banner.
03-business-card: card-print-3.5x2in.pdf = print file (2 pages: front and back, 3.5 x 2 in). Send it to the printer as is.
   If the printer asks for bleed (3.75 x 2.25 in), tell me and I will make that version.
   card-front-300dpi.png and card-back-300dpi.png = previews. business-card-source.html = editable (replace the [ ] text).
04-letterhead: letterhead-A4.pdf = print file (A4). letterhead-source.html = editable.
05-email-signature: signature.html = editable. signature-logo.png must be hosted online (put it on any public URL and
   replace https://YOUR-HOST/signature-logo.png), because email apps block inline SVG.
06-presentation: title-slide-1920x1080.pdf and .png = title slide. title-slide-source.html = editable.
07-website: website-header-1440x720.png = preview of the website header. website-header.html = editable.
08-favicon: favicon.svg (browser tab), favicon-32.png, apple-touch-icon-180.png (iPhone home screen), icon-512.png (app icon).
09-website-agent-prompt.md: the instructions to give the website agent so it replaces the old logo on the site.

Fonts: Geist is embedded in every HTML and PDF. Arabic text uses IBM Plex Sans Arabic when it is installed; otherwise your system Arabic font.
